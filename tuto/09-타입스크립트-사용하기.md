# 09. TypeScript와 함께 사용하기

Ohm은 기본적으로 TypeScript와 큰 설정 없이도 잘 작동합니다. 핵심 API에 대한 타입 정의가 기본 제공되기 때문입니다. (다만 자주 쓰이지 않는 일부 API는 아직 타입이 없을 수 있는데, 빠진 부분을 발견하면 [GitHub 이슈](https://github.com/ohmjs/ohm/issues/new)로 제보하거나 PR을 보낼 수 있습니다.)

여기서는 한 단계 더 나아가서, **내가 만든 문법 전용 타입 정의**를 자동으로 생성하는 방법을 소개합니다.

## 왜 그래머 전용 타입이 필요한가?

기본 타입만으로는 시맨틱 액션을 작성할 때 다음과 같은 걸 컴파일 타임에 확인할 수 없습니다.

- 액션 함수의 인자 개수가 그 규칙이 만들어내는 값의 개수와 맞는지
- 오퍼레이션의 리턴 타입이 일관적인지

그래머 전용 타입 정의를 생성하면 다음이 가능해집니다.

- TypeScript 컴파일러가 시맨틱 액션의 인자 개수/리턴 타입을 검사해줌
- VS Code 같은 IDE에서 액션 이름 자동완성, 인자 타입(`IterationNode`, `NonterminalNode`, `TerminalNode`) 툴팁 표시

## 설정 방법

### 1. `@ohm-js/cli` 설치

```bash
npm install -D @ohm-js/cli
```

### 2. 문법을 별도 `.ohm` 파일로 분리

아직 문법이 JavaScript 문자열 안에 있다면, `.ohm` 확장자를 가진 별도 파일로 옮깁니다.

예: `src/my-grammar.ohm`

```
MyGrammar {
  greeting = "Hello" | "Hola"
}
```

### 3. Ohm CLI로 번들과 타입 정의 생성

```bash
npx ohm generateBundles --withTypes 'src/*.ohm'
```

이 명령을 실행하면 `src/my-grammar.ohm` 파일 기준으로 다음 두 파일이 생성됩니다.

- `src/my-grammar.ohm-bundle.js` — 문법이 담긴 번들 파일
- `src/my-grammar.ohm-bundle.d.ts` — 이 문법 전용 타입 정의 파일

### 4. 번들 불러오기

```ts
import grammar from './my-grammar.ohm-bundle';
```

이렇게 불러온 `grammar`는 여러분의 문법에 딱 맞는 타입 정보를 가지고 있어서, 이후 `createSemantics()`, `addOperation()` 등을 사용할 때 TypeScript가 인자 개수와 타입을 검사해줍니다.

더 자세한 실전 예시는 [Ohm 저장소의 TypeScript 예제](https://github.com/ohmjs/ohm/blob/main/examples/typescript/src/arithmetic.ts)를 참고하세요.

## 요약

| 단계 | 명령/파일 |
|---|---|
| CLI 설치 | `npm install -D @ohm-js/cli` |
| 문법 파일 분리 | `src/my-grammar.ohm` |
| 번들 + 타입 생성 | `npx ohm generateBundles --withTypes 'src/*.ohm'` |
| 사용 | `import grammar from './my-grammar.ohm-bundle'` |
