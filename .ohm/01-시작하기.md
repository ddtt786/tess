# 01. 시작하기

## 설치하기

### Node.js에서 사용하기

npm, yarn, pnpm 중 편한 도구로 설치합니다.

```bash
npm install ohm-js
# 또는
yarn add ohm-js
# 또는
pnpm add ohm-js
```

설치 후 이렇게 불러옵니다.

```js
const ohm = require('ohm-js');
```

ES 모듈(import 문법)을 쓴다면 이렇게 씁니다.

```js
import * as ohm from 'ohm-js';
```

### 브라우저에서 바로 사용하기

`<script>` 태그 하나만 추가하면 됩니다.

```html
<!-- 개발용 -->
<script src="https://unpkg.com/ohm-js@17/dist/ohm.js"></script>

<!-- 최소화(압축) 버전, 더 빠른 로딩 -->
<script src="https://unpkg.com/ohm-js@17/dist/ohm.min.js"></script>
```

이렇게 하면 전역 변수 `ohm`이 만들어집니다.

### Deno에서 사용하기

```js
import * as ohm from 'https://unpkg.com/ohm-js@17';
```

## 기본 개념: 문법(Grammar)과 매칭(Matching)

Ohm을 쓰는 흐름은 항상 두 단계입니다.

1. **문법을 정의한다** — "어떤 문자열이 올바른가"에 대한 규칙을 Ohm 언어로 작성
2. **문법으로 입력을 검사한다** — `match()` 메서드로 실제 문자열이 규칙에 맞는지 확인

## 첫 번째 문법 만들기

가장 간단한 방법은 JavaScript 문자열(템플릿 리터럴)에 직접 문법을 적고 `ohm.grammar()`로 인스턴스를 만드는 것입니다.

```js
const myGrammar = ohm.grammar(String.raw`
  MyGrammar {
    greeting = "Hello" | "Hola"
  }
`);
```

> 💡 **왜 `String.raw`를 쓰나요?**
> 문법 안에 `\` 같은 이스케이프 문자가 들어갈 수 있기 때문에, JavaScript가 이 문자들을 미리 해석해버리지 않도록 `String.raw`를 붙인 템플릿 리터럴을 쓰는 것이 권장됩니다. `String.raw`를 안 쓰면 `\n` 같은 걸 `\\n`처럼 이중으로 이스케이프해야 해서 번거롭습니다.

위 문법을 해석하면 이렇습니다.

- 문법의 이름은 `MyGrammar`
- 이 문법에는 `greeting`이라는 규칙(rule) 하나가 있음
- `greeting`은 `"Hello"` 또는 `"Hola"`라는 글자와 정확히 일치해야 함

### 별도 파일로 문법 관리하기 (Node.js)

프로젝트가 커지면 문법을 `.ohm` 확장자를 가진 별도 파일로 분리하는 것이 좋습니다.

`myGrammar.ohm` 파일:

```
MyGrammar {
  greeting = "Hello" | "Hola"
}
```

이제 이 파일을 읽어서 문법을 만듭니다.

```js
const fs = require('fs');
const ohm = require('ohm-js');

const contents = fs.readFileSync('myGrammar.ohm', 'utf-8');
const myGrammar = ohm.grammar(contents);
```

## 문법으로 입력 검사하기: `match()`

문법 객체를 만들었으면, `match()` 메서드에 문자열을 넣어 검사할 수 있습니다.

```js
const userInput = 'Hello';
const m = myGrammar.match(userInput);

if (m.succeeded()) {
  console.log('사람이군요, 반갑습니다.');
} else {
  console.log('인사말이 아니네요!');
}
```

`match()`의 결과는 **MatchResult** 객체이며, 다음 두 메서드로 성공/실패를 확인합니다.

- `m.succeeded()` → 매칭에 성공했으면 `true`
- `m.failed()` → 매칭에 실패했으면 `true`

이렇게만 하면 "이 문자열이 문법에 맞는지 아닌지"만 알 수 있습니다. 매칭된 내용을 가지고 무언가를 계산하거나 변환하려면 **Semantics(시맨틱)** 라는 개념이 필요한데, 이건 [03-시맨틱-액션과-오퍼레이션.md](./03-시맨틱-액션과-오퍼레이션.md)에서 다룹니다.

## 디버깅 살짝 맛보기

문법이 왜 실패했는지 궁금할 때는 `match()` 대신 `trace()`를 써보면 파서가 어떤 결정을 내렸는지 단계별로 볼 수 있습니다.

```js
const g = ohm.grammar('G { start = letter+ }');
console.log(g.trace('ab').toString());
```

출력 결과는 대략 이렇게 생겼습니다 (✓는 성공, ✗는 실패를 의미합니다).

```
ab         ✓ start ⇒  "ab"
ab           ✓ letter+ ⇒  "ab"
ab             ✓ letter ⇒  "a"
ab                 ✓ lower ⇒  "a"
b              ✓ letter ⇒  "b"
b                  ✓ lower ⇒  "b"
               ✗ letter
           ✓ end ⇒  ""
```

또한 [온라인 에디터(https://ohmjs.org/editor)](https://ohmjs.org/editor)를 사용하면 문법과 입력을 실시간으로 시각화해서 볼 수 있습니다. 문법을 배우는 동안에는 이 온라인 에디터를 옆에 켜두고 실험해보는 걸 강력히 추천합니다.

## 정리

- 설치: `npm install ohm-js`
- 문법 작성: `ohm.grammar(String.raw\`...\`)`
- 문법 검사: `grammar.match(입력문자열)` → `MatchResult`
- 결과 확인: `.succeeded()` / `.failed()`
- 디버깅: `grammar.trace(입력문자열)` 또는 온라인 에디터
