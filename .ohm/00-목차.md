> 이 튜토리얼은 [Ohm 공식 문서](https://ohmjs.org/docs/intro)와 [Ohm GitHub 저장소](https://github.com/ohmjs/ohm)의 내용을 바탕으로, 처음 Ohm을 접하는 사람도 쉽게 따라올 수 있도록 한국어로 재구성한 자료입니다.

## Ohm이 뭔가요?

**Ohm**은 JavaScript/TypeScript에서 사용할 수 있는 **파서(parser) 생성 도구**입니다. 쉽게 말하면, "이런 형태의 문자열만 올바른 문법이다"라는 규칙(문법, grammar)을 정의해두면, Ohm이 그 규칙에 맞춰 입력 문자열을 분석해주는 라이브러리입니다.

예를 들어 다음과 같은 것들을 만들 때 사용할 수 있습니다.

- 나만의 설정 파일 포맷을 읽는 파서
- 계산기처럼 수식을 해석하는 인터프리터
- 미니 프로그래밍 언어의 컴파일러
- 채팅 명령어, 검색 쿼리 문법 분석기

Ohm의 가장 큰 특징은 **"문법 정의"와 "그 문법을 해석해서 무언가를 하는 코드(시맨틱 액션)"를 완전히 분리**한다는 점입니다. 이 덕분에 문법 자체는 순수하게 "이 입력이 올바른가?"만 판단하고, 실제 동작(계산하기, 변환하기 등)은 별도의 JavaScript 코드로 작성합니다. 그래서 문법을 읽기도 쉽고, 재사용하기도 쉽습니다.

Ohm의 문법 언어는 **PEG(Parsing Expression Grammar)** 라는 방식을 기반으로 하며, 좌재귀(left recursion)까지 지원해서 `1 + 2 + 3` 같은 왼쪽 결합 연산자도 자연스럽게 표현할 수 있습니다.
